# Customer privacy before publication

Before creating or updating public content, every contributor and agent must anonymize private customer context in PR titles, bodies, comments and reviews; branch names and commit messages; and committed code, tests, fixtures and documentation. Never copy private customer data from support threads, incident investigations, logs or connected sources into this repository.

Remove customer names and organization, repository, domain, tenant and account identifiers; customer-identifying keys, paths and log excerpts; and private customer job, support or incident links. Treat credentials, known tokens and secrets as private. Use neutral wording, synthetic data and minimal reproducible examples.

Check screenshot/recording pixels, captions and filenames before publishing. Use synthetic reproductions or keep identifying evidence private, never publish first and scrub later.

Preserve this repository's public identity, dependencies and intentionally public attributions, including public authors and third-party software. Never add a real customer-name blacklist.

If an inadvertent disclosure exists, stop propagating it and flag it privately for authorized cleanup. Do not delete content or rewrite history without approval.
